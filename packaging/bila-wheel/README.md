# Bila-G2P 1.0.0 Lightweight Wheel
This independent distribution depends on the unmodified upstream sea-g2p 0.10.0 wheel. Studio UI retains MIT; upstream SEA-G2P retains Apache-2.0 and third-party converter terms remain unchanged. No Rust compilation is needed on supported wheel platforms. Build using the repository staging script; do not build this directory directly without staging assets.
